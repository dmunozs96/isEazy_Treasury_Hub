# Bank Statement Samples

Place one sample Excel export per bank here.

**Naming convention:** `<BANK_NAME>_sample.xlsx`  
Example: `SANTANDER_sample.xlsx`, `BBVA_sample.xlsx`, `CAIXABANK_sample.xlsx`

**Requirements:**
- One file per bank
- Real column structure — fake amounts and IBANs are fine
- Include at least 10–20 rows of movements
- Include header row(s) if the bank export has them

**Purpose:** These files will be analysed to build the normalization mapping for each bank's parser. Do not delete them — they are the source of truth for parser design.

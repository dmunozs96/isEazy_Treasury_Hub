# Transaction Description Samples

Place a text or Excel file here with 30–50 anonymized bank transaction descriptions.

**What we need:** Only the description/concept text from bank statements. Amounts and IBANs are not needed.

**Format — either:**
- A plain text file, one description per line
- An Excel file with a single column "Description"

**Example descriptions:**
```
TRANSF. RECIBIDA DE ISEAZY AUTHORING SL
RECIBO NOMINAS MARZO 2026
LIQUIDACION IVA 1T 2026 AEAT
PAGO PROVEEDOR ADOBE SYSTEMS
REMESA CLIENTES ABRIL 2026
CUOTA PRESTAMO BBVA REF 2023/045
```

**Purpose:** These will be used to seed the initial classification rules engine before go-live, ensuring high auto-classification coverage from day one.

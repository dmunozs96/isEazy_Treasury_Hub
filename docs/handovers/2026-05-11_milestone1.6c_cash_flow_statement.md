## 1. What Was Done

### Backend - Schemas

- `CashFlowPeriod`
- `CashFlowRow`
- `CashFlowSectionSummary`
- `CashFlowStatement`

### Backend - Analytics Router

Added two endpoints:

- `GET /api/v1/analytics/cashflow`
- `GET /api/v1/analytics/cashflow/export`

Supported query params:

- `granularity=weekly|monthly`
- `date_from=YYYY-MM-DD`
- `date_to=YYYY-MM-DD`
- `company_id=<uuid>`
- `include_intercompany=true|false`

Behavior:

- Aggregates movements by period and cash-flow category.
- Groups rows by cash-flow section: operating, investing, financing, internal, unclassified.
- Returns section totals and net cash flow by period.
- Defaults to excluding confirmed intercompany movements from the consolidated statement.
- Provides Excel export using `openpyxl`.

Also fixed the dashboard weekly cash-flow SQL expression by replacing `func.case(...)` with SQLAlchemy `case(...)`.

### Frontend - Cash Flow View

- Refresh action.
- Excel export action.
- Statement table with section totals, category rows, period columns, and net cash flow total.

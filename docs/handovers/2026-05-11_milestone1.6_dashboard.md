## 1. What Was Done

### Backend — Schemas (`backend/app/schemas/analytics.py`)

New file with three Pydantic models:

- **`CompanyCashPosition`** — per-company cash summary:
  - `last_balance`: most recent `balance_after` summed across all accounts (NULL if no balance data)
  - `net_flow`: SUM of all movement amounts (always available as fallback)
  - `has_balance_data`: flag so frontend can show a disclaimer when using net_flow as approximation
- **`WeeklyCashFlow`** — one entry per ISO week:
  - `week_start`, `week_label` ("W20 2026"), `inflow`, `outflow`, `net`
- **`DashboardSummary`** — top-level response:
  - `cash_by_company`, `total_cash`, `net_flow_wtd`, `pending_ic_matches`, `in_transit_ic`, `unresolved_ic`, `weekly_cash_flow`, `as_of`

### Backend — Router (`backend/app/routers/analytics.py`)

Single endpoint: `GET /api/v1/analytics/dashboard`

**Cash position logic (3-step):**
1. Find latest `balance_after` per bank account (most recent non-NULL value by `value_date`)
2. Compute net flow per bank account (SUM of all amounts) as fallback
3. Aggregate both values by company via `bank_accounts` → `companies` join

**Other computations:**
- `net_flow_wtd` = SUM of amounts where `value_date` is between last Monday and today
- IC counts = GROUP BY `status` on `intercompany_matches`
- Weekly cash flow = DATE_TRUNC('week') + conditional SUM for inflow/outflow, last 13 weeks

**Cash position total:** prefers `last_balance` when available, falls back to `net_flow` per company.

## 3. Cash Position Design Note

Treasury cash position requires an opening balance to be meaningful. The current implementation uses `balance_after` from the most recent movement per bank account — this works for banks that export the running balance (Santander, BBVA, CaixaBank, etc.). Banks that don't export balance (some Eurocaja Rural and Ruralvia formats) will show `net_flow` as an approximation with an amber disclaimer in the UI.

Once enough movements are imported across a full period, `balance_after` coverage will be ~100% and the disclaimer will disappear.
